# การดูแลสายสวนและถุงปัสสาวะ

---

## 1. หลักการสำคัญที่ต้องจำเสมอ: หัวใจของการป้องกันการติดเชื้อ

การดูแลที่ถูกต้องช่วยป้องกันไม่ให้เชื้อโรคย้อนกลับเข้าสู่ร่างกายของผู้ป่วยผ่านทางสายสวน

| หลักการ | เพราะอะไร? (เหตุผล) |
| :--- | :--- |
| **จัดตำแหน่งถุงปัสสาวะให้ถูกต้อง** | เพื่อป้องกันน้ำปัสสาวะที่อาจมีเชื้อโรคไหลย้อนกลับเข้าสู่กระเพาะปัสสาวะ |
| 1. **ต้องอยู่ต่ำกว่าระดับกระเพาะปัสสาวะ (เอว) เสมอ** | อาศัยแรงโน้มถ่วงให้น้ำปัสสาวะไหลลงทางเดียว |
| 2. **ห้ามวางถุงปัสสาวะกับพื้นโดยตรง** | พื้นเป็นแหล่งสะสมของเชื้อโรค การสัมผัสอาจทำให้เชื้อโรคเข้าสู่ระบบผ่านทางปลายท่อได้ |
| **ดูแลสายให้โล่งและเป็นระบบปิด** | เพื่อให้น้ำปัสสาวะไหลได้สะดวกและป้องกันเชื้อโรคจากภายนอก |
| 1. **ตรวจสอบสายไม่ให้พับงอหรือถูกกดทับ** | การอุดกั้นทำให้น้ำปัสสาวะคั่งค้างและเป็นแหล่งเพาะเชื้อ |
| 2. **รักษาระบบให้เป็น "ระบบปิด" เสมอ** | ตรวจสอบว่าข้อต่อทุกจุดแน่นหนา ไม่มีรอยรั่วซึม เพื่อไม่ให้มีช่องทางให้เชื้อโรคเข้าไปได้ |
| **รักษาความสะอาดอย่างเคร่งครัด** | เพื่อลดจำนวนเชื้อโรคบริเวณรอบๆ สายสวน |
| 1. **ล้างมือให้สะอาดทุกครั้ง** | ก่อนและหลังสัมผัสสายสวน ถุงปัสสาวะ หรือระหว่างการดูแลผู้ป่วย |

> ⚠️ **ข้อควรระวัง**
> **ห้าม** ยกถุงปัสสาวะสูงกว่าระดับเอวของผู้ป่วยโดยเด็ดขาด หากจำเป็นต้องเคลื่อนย้ายผู้ป่วยและต้องยกถุงสูงขึ้นชั่วคราว ให้ใช้มือพับสายสวนปัสสาวะไว้ก่อน และรีบจัดให้อยู่ในตำแหน่งที่ถูกต้องทันทีเมื่อเสร็จสิ้น

## 2. การดูแลสุขอนามัยประจำวัน

การทำความสะอาดอย่างสม่ำเสมอเป็นวิธีที่ดีที่สุดในการป้องกันการติดเชื้อจากผิวหนังรอบนอกเข้าสู่ท่อปัสสาวะ

- **ความถี่:** ทำความสะอาดอย่างน้อยวันละ 2 ครั้ง (เช้า-เย็น) และทุกครั้งหลังการขับถ่ายอุจจาระ
- **อุปกรณ์:** สบู่อ่อนและน้ำสะอาด, ผ้าสะอาดหรือสำลี
- **ขั้นตอน:**
    1. ล้างมือให้สะอาดและสวมถุงมือ (ถ้ามี)
    2. ใช้สบู่และน้ำสะอาดล้างบริเวณอวัยวะเพศและรอบๆ บริเวณที่สายสวนสอดอยู่
    3. **สำหรับผู้หญิง:** เช็ดทำความสะอาดจาก **ด้านหน้าไปด้านหลังเสมอ** เพื่อป้องกันการนำเชื้อโรคจากทวารหนักมาสู่ท่อปัสสาวะ
    4. **สำหรับผู้ชาย:** หากไม่ได้ขลิบหนังหุ้มปลาย ให้รูดหนังหุ้มปลายลงเบาๆ เพื่อทำความสะอาดแล้วเช็ดให้แห้ง จากนั้นรูดหนังหุ้มปลายกลับเข้าที่เดิมทุกครั้ง
    5. ซับบริเวณที่ทำความสะอาดให้แห้งสนิทด้วยผ้าสะอาด
    6. ขณะทำความสะอาด สามารถขยับสายสวนหมุนไปมาเล็กน้อยอย่างเบามือ เพื่อป้องกันการยึดติดของปลายสาย
- **ข้อห้าม:** ไม่ควรโรยแป้งฝุ่นบริเวณอวัยวะสืบพันธุ์ เพราะอาจทำให้เกิดการอับชื้นและสะสมเชื้อโรคได้

## 3. ขั้นตอนการเทปัสสาวะทิ้งอย่างปลอดเชื้อ

ควรเทปัสสาวะทิ้งเมื่อมีปริมาณ **2 ใน 3 ของถุง** หรืออย่างน้อยทุก 8 ชั่วโมง เพื่อไม่ให้น้ำหนักของถุงดึงรั้งสายสวนมากเกินไป และเพื่อลดการเจริญเติบโตของแบคทีเรียในถุง

1.  **เตรียมอุปกรณ์:**
    - ภาชนะสำหรับรองรับปัสสาวะที่สะอาดและใช้เป็นการเฉพาะ
    - สำลีชุบแอลกอฮอล์ 70%
    - ถุงมือสะอาด (ถ้ามี)

2.  **ขั้นตอนการเท:**
    - ล้างมือให้สะอาดและสวมถุงมือ
    - นำภาชนะรองรับไปวางในตำแหน่งที่เหมาะสม (บนพื้นห้องน้ำที่สะอาด)
    - ใช้สำลีชุบแอลกอฮอล์เช็ดทำความสะอาดบริเวณ **ปลายท่อเปิดสำหรับเท (Drainage port)** ของถุงปัสสาวะ **ก่อน** เปิด
    - เปิดจุกที่ปลายท่อออกอย่างระมัดระวัง **อย่าให้ปลายท่อสัมผัสกับขอบภาชนะหรือพื้น**
    - ปล่อยให้น้ำปัสสาวะไหลลงในภาชนะจนหมดถุง
    - เมื่อหมดแล้ว ใช้สำลีชุบแอลกอฮอล์ก้อนใหม่เช็ดทำความสะอาดปลายท่ออีกครั้ง **ก่อน** ปิดจุกให้สนิท
    - นำน้ำปัสสาวะไปเททิ้งในชักโครก สังเกตสีและลักษณะของปัสสาวะก่อนทิ้ง
    - ทำความสะอาดภาชนะที่ใช้รองรับปัสสาวะให้เรียบร้อย
    - ถอดถุงมือและล้างมือให้สะอาดอีกครั้ง

## 4. สัญญาณอันตรายที่ต้องสังเกตและรายงานแพทย์/พยาบาลทันที

บทบาทที่สำคัญที่สุดของผู้ดูแลคือการสังเกตความผิดปกติและแจ้งทีมสุขภาพได้อย่างรวดเร็ว

| ประเภทของสัญญาณ | อาการที่ต้องสังเกต | การปฏิบัติ |
| :--- | :--- | :--- |
| **อาการของผู้ป่วย** | - มีไข้ หนาวสั่น<br>- ปวดแสบ ปวดร้อน หรือเจ็บบริเวณท่อปัสสาวะ<br>- ปวดบริเวณท้องน้อยหรือบั้นเอว | **หยุดกิจกรรมและรายงานพยาบาลหรือแพทย์ทันที** |
| **ลักษณะของปัสสาวะ** | - ปัสสาวะขุ่น มีตะกอน<br>- มีกลิ่นเหม็นฉุนผิดปกติ<br>- มีสีผิดปกติ เช่น สีแดง (เลือด) หรือสีน้ำล้างเนื้อ | **หยุดกิจกรรมและรายงานพยาบาลหรือแพทย์ทันที** |
| **การทำงานของสายสวน** | - ไม่มีปัสสาวะไหลลงถุงเป็นเวลาหลายชั่วโมง ทั้งที่ผู้ป่วยดื่มน้ำตามปกติ<br>- มีปัสสาวะรั่วซึมออกมาข้างสายสวน<br>- สายสวนเลื่อนหลุดออกมา | **หยุดกิจกรรมและรายงานพยาบาลหรือแพทย์ทันที** |

> ⚠️ **ข้อควรระวังและขอบเขตหน้าที่ของผู้ดูแล**
>
> - **ห้าม** ดึง ดัน หรือพยายามสวนล้างสายสวนปัสสาวะด้วยตนเองเมื่อเกิดการอุดตัน
> - **ห้าม** ถอดหรือเปลี่ยนสายสวนปัสสาวะด้วยตนเองโดยเด็ดขาด การเปลี่ยนสายต้องทำโดยแพทย์หรือพยาบาลเท่านั้น
> - **หน้าที่หลักของผู้ดูแล** คือการดูแลความสะอาด สังเกตการณ์ และรายงานความผิดปกติแก่ทีมสุขภาพ เพื่อให้ผู้ป่วยได้รับการดูแลที่ถูกต้องและปลอดภัย
